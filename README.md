# Nexona Flow - Automated Price Tracker

A Python automation script that monitors product prices on e-commerce sites and sends instant Telegram notifications when the price drops below a specified threshold.

## Features
- Real-time price monitoring
- Telegram notifications for price drops
- Configurable price threshold
- Lightweight and easy to deploy

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Configure your Telegram Bot Token and Chat ID in `tracker.py`.
3. Run: `python tracker.py`

## Tech Stack
Python, BeautifulSoup, Requests, Telegram API
